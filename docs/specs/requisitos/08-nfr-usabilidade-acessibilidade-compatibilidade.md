# Non-Functional Requirements — Usability, Accessibility, Responsiveness and Compatibility

- **RNF116:** The System SHALL allow a first-time user to create a task and send a chat message without requiring external training documentation.
- **RNF117:** The System SHALL support keyboard navigation for all primary interactive elements.
- **RNF118:** The System SHALL provide text alternatives for meaningful non-text interface elements.
- **RNF119:** The System SHALL provide a usable interface for viewport widths from 360 pixels to 1920 pixels.
- **RNF120:** The System SHALL support the two most recent stable versions of Google Chrome, Mozilla Firefox, Microsoft Edge, and Safari.
