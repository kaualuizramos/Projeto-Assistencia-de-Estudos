# Non-Functional Requirements — Performance and Availability

> These requirements were written for a web version with a backend. The current product is a single-user local desktop application without HTTP endpoints, so they are kept for traceability and marked as not applicable. They become applicable only if a web or backend version is built.

- **RNF101 (not applicable to the desktop version):** The application has no endpoints and no concurrent remote users. Original requirement: "The System SHALL process at least 95% of requests to its own endpoints, excluding those waiting for the external AI service, within 2 seconds with up to 100 concurrent authenticated users."
- **RNF102 (not applicable to the desktop version):** The application has no backend and no browser; the response of the AI service is rendered directly in the application window. Original requirement: "WHEN a response is received from the external AI service, the System SHALL deliver it to the user's browser within 2 seconds after its receipt by the backend."
- **RNF103 (not applicable to the desktop version):** The application runs on the user's own computer, without a service whose availability can be monitored. Original requirement: "The System SHALL provide at least 99% monthly availability of its own endpoints, measured by health checks every minute, excluding scheduled maintenance and unavailability of the external AI service."
